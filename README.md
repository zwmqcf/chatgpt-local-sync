# AI 对话流转

一个将 ChatGPT 对话同步到本地，并支持整理、筛选和再次提取使用的浏览器用户脚本。

## 主要功能

- 将 ChatGPT 对话增量同步到本地
- 只处理新增和发生变化的对话
- 按命名规则自动整理到对应文件夹
- 识别本地文件移动、删除等变化
- 筛选需要的对话
- 提取为 JSON / Markdown
- 支持 ZIP 或普通文件形式，方便继续交给其他 AI 使用

## 安装

1. 安装用户脚本管理器（例如 ScriptCat）
2. 安装本项目提供的用户脚本
3. 打开或刷新 ChatGPT 页面
4. 点击右侧出现的工具入口

## 第一次使用

首次使用时选择一个本地文件夹作为资料库，然后点击开始导出。

之后有新的聊天或者已有聊天发生更新时，再次同步即可。

## 自动整理

可以在管理页面设置分类规则。

设置完成后，符合命名规则的对话会自动整理到对应目录。

## 提取对话

从本地资料库中筛选需要的对话，可以导出为 JSON 或 Markdown，用于后续 AI 工作流。

## 支持平台

目前支持：

- https://chatgpt.com
- https://chat.openai.com
