# AI 对话流转

一个把 ChatGPT 对话持续同步到电脑本地、自动整理，并在需要时重新提取出来继续使用的浏览器用户脚本。

它不是每次重新导出一整份聊天记录，而是维护一个会持续更新的本地对话资料库：已经保存过的内容不会反复处理，有新增或变化时再继续同步。

## 主要功能

- 将 ChatGPT 对话增量同步到本地
- 同时保存 JSON 与 Markdown
- 按对话标题规则自动分类到不同文件夹
- 识别本地文件的移动、删除和目录变化
- 按时间、标题、文件夹等条件筛选对话
- 将选中的对话重新提取为 JSON / Markdown
- 支持 ZIP 或普通文件形式，方便继续交给其他 AI 使用
- 同步时优先保留已经保存的对话内容，遇到无法安全判断的情况会停止自动处理并提示确认

## 安装

推荐通过 ScriptCat 安装本项目的用户脚本。

也可以直接使用仓库中的：

`chatgpt-local-sync.user.js`

安装完成后，打开或刷新 ChatGPT 页面，右侧会出现「⇄」入口。

## 第一次使用

1. 安装脚本
2. 打开或刷新 ChatGPT
3. 点击页面右侧的「⇄」按钮
4. 进入「导出」
5. 选择一个电脑里的文件夹作为本地资料库
6. 点击「开始导出」

第一次设置完成以后，之后有新的聊天或者原来的聊天发生更新，再同步一次即可。

## 自动整理

进入：

**管理 → 分类规则**

可以为自己的对话命名习惯设置规则和目标文件夹。

设置完成后，符合命名规则的对话会在同步时自动整理到对应目录。你也可以直接在电脑文件管理器中移动或删除已经同步的文件，之后通过「管理」检查变化，工具会尽量理解这些调整并保持本地资料库一致。

## 重新拿去使用

进入：

**提取 → 筛选对话 → 选择需要的对话 → 开始提取**

可以按时间、标题、文件夹等条件筛选，只拿出当前需要的一批对话，并选择 JSON、Markdown、ZIP 或普通文件形式。
