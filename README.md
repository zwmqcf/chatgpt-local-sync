# AI 对话流转

一个把 ChatGPT 对话持续保存到电脑本地、自动整理，并在需要时重新提取出来继续使用的浏览器用户脚本。

它不是每次重新导出一整份聊天记录，而是维护一个会持续更新的本地对话资料库：

- 已经保存过的内容不会反复处理
- 有新的对话时继续补充
- 原有对话发生更新时继续同步
- 本地整理过的文件也可以继续管理和使用
- 需要交给其他 AI 时，可以只提取当前需要的一部分

## 主要功能

### 持续保存 ChatGPT 对话

将 ChatGPT 对话增量同步到电脑本地。

默认同时保存：

- JSON
- Markdown

第一次完成保存以后，之后再次同步时只需要处理新增或发生变化的内容。

---

### 自动整理

可以根据对话标题设置分类规则，将不同类型的 Conversation 自动保存到对应文件夹。

进入：

**管理 → 分类规则**

你也可以直接在电脑文件管理器中移动或删除已经保存的文件。

之后通过插件的「管理」功能检查变化，插件会根据本地文件的实际状态进行处理。

---

### 按需提取

本地资料库保存的是长期 Conversation 资产，但真正需要交给其他 AI 使用时，通常不需要一次拿出全部内容。

进入：

**提取 → 筛选对话 → 选择需要的对话 → 开始提取**

可以按照：

- 时间
- 标题
- 文件夹
- 其他筛选条件

选择需要的 Conversation。

支持提取为：

- JSON
- Markdown
- ZIP
- 普通文件

方便继续交给 ChatGPT、其他 AI 或其他工具使用。

## 第一次使用

1. 安装用户脚本
2. 打开或刷新 ChatGPT
3. 点击页面右侧的「⇄」按钮
4. 进入「导出」
5. 选择电脑中的一个文件夹作为本地资料库
6. 点击「开始导出」

第一次保存完成后，这个文件夹就会作为你的本地 Conversation 资料库。

以后有新的聊天，或者原有聊天发生更新，再同步一次即可。

---

## 数据安全原则

这个工具优先保证已经保存到本地的 Conversation 不会因为一次同步异常而被轻易覆盖或删除。

在无法安全判断远端或本地状态时，插件会优先停止自动处理并提示检查，而不是为了“同步成功”直接丢弃已有内容。
